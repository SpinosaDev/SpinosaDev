### 🚀 Sobre Mí

Ingeniero de software enfocado en la construcción de **productos empresariales de misión crítica, arquitecturas distribuidas y soluciones de extremo a extremo (0 a 100)**:

* 🏢 **Plataformas SaaS de Telecomunicaciones:** Creador y arquitecto de **StockFlow Pro**, suite SaaS integral para operadoras de fibra óptica (FTTH) con backend en FastAPI, 27 módulos web aislados bajo RBAC, motor fiscal certificado **Veri\*factu (RD 1007/2023)** y algoritmos de reaprovisionamiento inteligente (EOQ).
* 📱 **Desarrollo Móvil & Offline-First:** Especialista en **Android Nativo y Kotlin Multiplatform (KMP/CMP)**. Diseño de experiencias reactivas con **Jetpack Compose**, persistencia local con **Room DB**, sincronización bidireccional resiliente, autenticación biométrica y captura de evidencias en campo.
* 🔒 **Sistemas, Criptografía Aplicada & Ciberseguridad:** Desarrollo de software seguro con modelo **Zero-Trust y Zero-Leak**. Creador de **DevVault**, gestor criptográfico con núcleo en **Rust (`vault-core`)** implementando **Argon2id**, cifrado AEAD (**XChaCha20-Poly1305 / AES-256-GCM**), intercambio efímero de claves (X25519-HKDF) y protección de memoria con `zeroize`.
* 🤖 **Ingeniería de Agentes & Automatización con IA:** Diseño y orquestación de sistemas multi-agente autónomos especializados (*backend, UI/UX, brand identity, security auditing*), protocolos MCP (*Model Context Protocol*) y flujos de trabajo de ingeniería asistida de alta precisión.

### 📦 Proyectos Destacados

#### 🌐 1. [StockFlow Pro](https://github.com/SpinosaDev/stockflow-pro-)
> **Plataforma Integral SaaS para Operadoras de Telecomunicaciones y Despliegues de Fibra Óptica (FTTH).**

* **Backend FastAPI Endurecido:** Arquitectura modular con 16 routers REST, control de acceso basado en roles (RBAC) y aislamiento estricto de inquilinos en base de datos.
* **CRM Web Industrial (27 Páginas Independientes):** Paneles administrativos y operativos para despacho de órdenes de trabajo (OTs), inventario, gestión de cuadrillas y tickets con SLAs.
* **Motor Fiscal Veri\*factu (RD 1007/2023):** Generación de facturas PDF 1.4 inmutables con encadenamiento criptográfico SHA-256 y códigos QR de verificación fiscal.
* **Reaprovisionamiento Inteligente (Auto-PO & EOQ):** Cálculo automatizado de lote económico de pedido y disparo de compras preventivas por umbrales mínimos.
* **App Móvil Android para Técnicos de Campo:** Solución nativa con sincronización offline-first, firma digital de partes, evidencias fotográficas y control de bobinas de fibra y cortes.
* **Calidad y Robustez:** Batería de más de **213 tests automatizados** cubriendo lógica de negocio, endpoints y seguridad.

```
FastAPI 0.109  ·  Python 3.12  ·  Jetpack Compose  ·  Kotlin 2.0  ·  Supabase RLS  ·  Veri*factu
```

#### 🔐 2. DevVault — Zero-Knowledge Secrets & Cryptographic Bridge
> **Gestor de Secretos y Contraseñas Local con Núcleo en Rust y Cliente Compose Multiplatform.**

* **Núcleo de Criptografía en Rust (`vault-core`):** Creado con foco en seguridad de memoria, derivación `Argon2id`, cifrado autenticado `XChaCha20-Poly1305` y limpieza garantizada de buffers sensibles en RAM (`zeroize`).
* **Canal E2EE en Tránsito:** Bridge criptográfico (`X25519-HKDF-AES256GCM`) para sincronización segura entre servidores locales/remotos y la bóveda física sin exposición de texto claro.
* **Cliente Compose Multiplatform (CMP):** Interfaz unificada orientada a Android, Desktop (JVM), Web (Wasm/JS) e iOS, impulsada por un servidor Ktor ultraligero.
* **Filosofía Zero-Leak:** Arquitectura diseñada para impedir filtraciones en logs, trazas o almacenamiento temporal.

```
Rust  ·  Kotlin Multiplatform  ·  Compose Multiplatform  ·  Argon2id  ·  XChaCha20-Poly1305  ·  Ktor
```
