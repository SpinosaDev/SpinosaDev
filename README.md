### 📦 Mi Proyecto Más Grande: [StockFlow Pro](https://github.com/dev4KoS/stockflow-pro-)

> **Plataforma completa para operadoras de fibra óptica y telecomunicaciones.**

Un sistema completo creado desde cero que une:
* **Backend potente:** Con 27 páginas aisladas de CRM, seguridad por roles y facturación fiscal con QR Veri\*factu (RD 1007/2023).
* **Motor inteligente de compras:** Detección de rotura de stock y pedidos automáticos a proveedores (Auto-PO).
* **App Android para técnicos:** Para registrar órdenes de trabajo en la calle, cortar bobinas y sacar fotos de incidencias sin necesitar cobertura de internet.
