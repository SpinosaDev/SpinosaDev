### 📦 Proyecto Destacado: [StockFlow Pro](https://github.com/dev4KoS/stockflow-pro-)

> **Plataforma integral para operadoras de telecomunicaciones y gestión de redes FTTH.**

Una suite completa desarrollada para resolver la operativa diaria entre oficina y personal de campo:
* **Backend & CRM:** 27 módulos web aislados con control de acceso por roles, gestión de stock, presupuestos, albaranes y facturación fiscal con QR Veri\*factu (RD 1007/2023).
* **Cadena de suministro:** Detección automática de stock bajo mínimos y emisión de órdenes de compra a proveedores.
* **App móvil nativa:** Diseñada para técnicos en campo, con soporte para trabajo sin conexión, registro de partes y gestión de bobinas de fibra.

```
┌──────────────────┐       ┌──────────────────┐       ┌──────────────────┐

│ (Técnicos campo) │       │   (API + CRM)    │       │ (PostgreSQL/RLS) │
└──────────────────┘       └──────────────────┘       └──────────────────┘
```
